# Tipografía

La jerarquía tipográfica usa la familia del sistema y una escala con tamaños, alturas de línea y pesos explícitos. Los valores de tipografía no varían entre los temas claro y oscuro; solo cambia el color semántico del texto.

Las clases de utilidad `text-display`, `text-headline`, `text-title`, `text-body`, `text-small` y `text-caption` conectan con esta escala, incluyendo altura de línea y peso.

## Cuándo usarlo / Reglas

Elige el nivel según la jerarquía de lectura y usa los tokens tipográficos o sus clases Tailwind. Mantén textos extensos legibles con alturas de línea de cuerpo; evita introducir tamaños y pesos aislados en una pantalla. Usa la familia monoespaciada para valores técnicos donde el código la establezca.
