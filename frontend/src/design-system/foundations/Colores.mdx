## Cuándo usarlo / Reglas

Usa tokens semánticos para la interfaz; nunca introduzcas colores literales. En Tailwind utiliza, por ejemplo, `bg-brand` o `text-foreground`, y en CSS la variable semántica correspondiente. No uses el color como único medio para comunicar un estado clínico.
