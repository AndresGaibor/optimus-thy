## Transiciones

| Desde                         | Acción                             | Destino                                                                       |
| ----------------------------- | ---------------------------------- | ----------------------------------------------------------------------------- |
| `/` (sin sesión)              | Redirección automática             | `/login`                                                                      |
| `/` (con sesión)              | Redirección automática             | `/{rolActivo}`                                                                |
| `/login`                      | Credenciales válidas               | `/medico`, `/investigador` o `/administrador` (según rol activo)              |
| `/login`                      | Pulsa “¿Olvidaste tu contraseña?”  | `/login/recuperar`                                                            |
| `/login`                      | Pulsa “Volver al inicio”           | `/`                                                                           |
| Ruta de otro rol              | Acceso con rol activo distinto     | Pantalla “Acceso denegado”, con enlace al inicio del rol activo               |
| Barra lateral (médico)        | “Pacientes” / “Inferencia”         | `/medico/pacientes`, `/medico/inferencia`                                     |
| Barra lateral (administrador) | “Usuarios” / “Roles” / “Auditoría” | `/administrador/usuarios`, `/administrador/roles`, `/administrador/auditoria` |
| AppShell, botón de rol        | Cambia de rol activo               | Inicio del nuevo rol                                                          |
| AppShell, “Cerrar sesión”     | Cierra la sesión                   | `/login`                                                                      |
| Ruta desconocida              | Navegación directa                 | NotFoundPage                                                                  |
