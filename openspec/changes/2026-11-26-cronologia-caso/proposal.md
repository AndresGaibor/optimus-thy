# Cronología del caso

Expose a privacy-conscious, institution-scoped timeline of case events and show it in the case page.

## Why
Clinicians need one chronological view of images, inferences, consents, decisions, and record changes when opening a case.

## Scope
Add a read-only chronology endpoint, its generated API contract, and a retryable frontend section. Keep event details concise and free of patient identity or long clinical text.
